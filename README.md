# Schadensfälle – Web-App

Schadensfälle bei Transportaufträgen nachhaken und bearbeiten – im Browser auf PC, Tablet und Handy.
Die Daten liegen in Google Drive (Cloud-Skript) und werden mit der Android-App abgeglichen.

Diese Seite wird über GitHub Pages ausgeliefert. Der Quelltext mit Tests, der Android-App und dem
Cloud-Skript liegt im Repository `aysetransport/Test` (Ordner `web/` und `cloud/`); Änderungen
bitte dort machen und hierher übernehmen.
